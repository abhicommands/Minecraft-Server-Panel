# Support

Minecraft Server Panel is an open-source project maintained on a best-effort
basis. There is no guaranteed response time, uptime commitment, private support
channel, or service-level agreement.

## Start here

Before requesting help:

1. Read the root [README](README.md) and the backend
   [documentation](server/README.md).
2. Use the latest release or current `main` branch and confirm Bun and Java meet
   the documented requirements.
3. Run `bun run check` for source installations or `minecraft-server-panel
   doctor` for release installations.
4. Search existing [issues](https://github.com/abhicommands/Minecraft-Server-Panel/issues),
   including closed issues.
5. Remove passwords, JWT secrets, cookies, IP addresses, world data, and other
   private information from logs before sharing them.

For a reproducible project defect, open a bug report using the repository issue
template. Feature ideas should use the feature-request template. GitHub Issues
are not a general Minecraft, Java, networking, Caddy, nginx, Linux, or macOS
support service; consult those projects' documentation for upstream problems.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md). Code of conduct
reports must follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Do not post either
kind of sensitive report publicly.

Questions may remain unanswered when they cannot be reproduced, target an
unsupported platform, omit required details, expose secrets, or are outside the
scope of this project. A clear minimal reproduction and relevant sanitized logs
make help much more likely.
